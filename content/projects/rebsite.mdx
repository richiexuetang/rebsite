This site. A personal portfolio built with [Next.js](https://nextjs.org/),
[Tailwind CSS](https://tailwindcss.com/),
[Contentlayer](https://www.contentlayer.dev/), and
[Upstash](https://upstash.com), and deployed to
[Vercel](https://vercel.com/).

Project content is authored as MDX and processed by Contentlayer at build time,
and per-page view counts are tracked with an edge function backed by Upstash
Redis.
